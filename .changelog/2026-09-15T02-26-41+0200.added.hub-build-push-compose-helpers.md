# Add Hub build/push helpers and improve compose

Added `_build.yml`, `_push.yml`, `Dockerfile.platform`, and `dc.sh` (same pattern as headless-camoufox) so local builds and Docker Hub pushes use dedicated compose files. Runtime `docker-compose.yml` now pulls `${DOCKERHUB_USERNAME:-harianto}/headless-obscura:latest`, sets `shm_size`, and aligns the container name with the service. Added `docker-compose.override.yml` for the external cloudflared network and host-gateway.
