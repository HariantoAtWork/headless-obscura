# Add docker-compose service for Obscura

Added `docker-compose.yml` with an `obscura` service that builds from the local `Dockerfile`, pins `platform: linux/amd64` to match upstream Obscura release binaries, maps host port `${OBSCURA_HOST_PORT:-9222}` to container `9222`, and exposes environment overrides for `OBSCURA_PORT` and `OBSCURA_INTERNAL_PORT`.

This makes local startup easier with `docker compose up --build` while keeping the same runtime behaviour as the direct `docker run` command.
