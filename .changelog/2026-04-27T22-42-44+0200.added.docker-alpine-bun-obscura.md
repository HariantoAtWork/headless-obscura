# Alpine Docker image with Bun and Obscura CDP

Added a multi-stage Dockerfile that keeps an Alpine userspace while satisfying Obscura’s glibc requirement: base `frolvlad/alpine-glibc:alpine-3.22_glibc-2.42`, Bun copied from `oven/bun:1-alpine`, install via `bun run obscura:install`, and a `socat` entrypoint because `obscura serve` binds CDP to `127.0.0.1` only (so `-p 9222:9222` works from the host).

Also added `package.json`, `scripts/utils/obscuraBinary.mjs`, `.dockerignore`, and `.gitignore` for `.tools/`.

Build (upstream ships **linux/amd64** only today): `docker build --platform linux/amd64 -t obscura-headless:alpine-bun .`

Remote clients: CDP JSON may advertise `ws://127.0.0.1:9223/...`; use your host and the published port (default **9222**) instead, e.g. `ws://localhost:9222/devtools/browser`.
